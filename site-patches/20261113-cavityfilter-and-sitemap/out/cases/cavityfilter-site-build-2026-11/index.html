核对日期：2026-11-13（北京时间）。本页是出海ABC为深圳康讯通（Kangxuntong）搭建独立站的第一方记录。文中只写已核对的注册、解析、邮箱、部署和站点结构，不是对某台机器的访问测速，也没有自购套餐做性能测试，因此不对加载速度或线路质量下结论。

说明关系#

该站面向海外买家，介绍康讯通在深圳生产的腔体滤波器、双工器与合路器，并接受询价。出海ABC负责从域名、解析、企业邮箱、源站部署到页面搭建与后续核对。产品规格以工厂原稿为准，没有在原稿中出现的指标，不以推测补全。

现站地址：cavityfilter.com。中文入口在 cavityfilter.com/zh/。

过程摘要#

  • 2026-11-11 16:43（北京时间），主域名 cavityfilter.com 在 Cloudflare 完成注册；约一分钟后注册复数域名 cavityfilters.com，用于跳转到主站。
  • 域名解析放在 Cloudflare 的名称服务器上，但页面由源站直接提供。2026-11-13 复核时，响应头为 nginx，未见内容分发网络的回源头。
  • 企业邮箱使用 Zoho Mail，对外地址为 sales@cavityfilter.com。已配置 SPF 与 DKIM，DMARC 策略为 p=none。
  • 源站运行 Ubuntu，Web 服务为 nginx 1.28.3。HTTP、www、复数域名以及直接访问服务器地址，均 301 跳转到 https://cavityfilter.com/。证书由 Let’s Encrypt 签发，并覆盖上述主机名。
  • 站点为中英文静态目录站。2026-11-13 复核时，站点地图共 186 条网址（中英文各 93 条）；与发布稿一致的规格书 PDF 为 70 份。

域名#

注册记录来自公开的 RDAP（核对于 2026-11-13，北京时间）。注册商为 Cloudflare, Inc.（IANA 编号 1910）。公开记录中没有付款金额，本页不写域名价格，价格以当时结算页为准。

域名注册时间（北京时间）到期时间（北京时间）用途

解析与证书#

名称服务器为 ainsley.ns.cloudflare.com 与 tim.ns.cloudflare.com。主域名、www 以及 cavityfilters.com 的 A 记录指向同一源站地址；复核时没有 AAAA 记录。

把域名放在 Cloudflare 做注册和解析，不等于已经启用了 Cloudflare 的内容分发网络。本次复核中，页面由源站 nginx 直接返回。

HTTPS 证书由 Let’s Encrypt 签发，通用名称为 cavityfilter.com，有效期为 2026-11-11 17:38 至 2027-02-09 17:38（北京时间），证书中同时包含 www.cavityfilter.com、cavityfilters.com 与 www.cavityfilters.com。

企业邮箱#

邮件交换记录指向 Zoho（mx.zoho.com、mx2.zoho.com、mx3.zoho.com）。SPF 为 v=spf1 include:zohomail.com ~all，并有 Zoho 域名验证记录。DKIM 使用 zoho._domainkey.cavityfilter.com。DMARC 为 v=DMARC1; p=none;。套餐档位与年费以 Zoho 当时说明为准，本页不写未核对的邮箱价格。

网站询价表会发送到 sales@cavityfilter.com，并同时提供电子邮件和即时通讯作为备选。

服务器与部署#

2026-11-13 可公开核对的事实如下：源站系统为 Ubuntu，Web 服务为 nginx 1.28.3；地址属于 IT7 Networks Inc（AS25820），反向解析落在 16clouds.com 域下。第三方地理库常把该网段标在美国，本页未做访问测速，因此不把机房城市或延迟写成结论，也不写入未在公开结算页核对过的套餐品牌和标价。

部署方式是将静态页面放到网站根目录，由 nginx 托管；缺页指向站点自己的 404 页面。

站点结构#

这是展示与询价型独立站，用于说明产品并接收询价，不是带购物车和在线收款的卖货站。页面为中英文对照。产品规格按工厂原稿核对；原稿未给出的指标，页面保留为以测试报告或原稿为准。

常见问题#

Q：这是不是一次服务器测速？

A：不是。本文核对的是域名、解析、证书、邮箱、跳转和站点结构。没有自购实测，不下性能结论。

Q：为什么不写服务器套餐和价格？

A：公开可核对的是系统、Web 服务、网络归属和跳转行为。套餐品牌与标价没有可引用的公开结算页，按本站规则不写。

Q：域名在 Cloudflare 注册，是不是已经用了它的内容分发网络？

A：不一定。本次复核时，解析在 Cloudflare，页面由源站直接返回。两者要分开看。

Q：复数域名是必须的吗？

A：不是必须，但这次一并注册了 cavityfilters.com，并统一跳转到主站，避免客户多输入一个 s 时离开本站。
