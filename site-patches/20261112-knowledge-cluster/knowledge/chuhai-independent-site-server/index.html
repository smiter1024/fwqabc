核对日期：2026-11-12（北京时间）。这是给中国中小企业、个体户、源头工厂做海外独立站时的选型顺序，不是优惠汇总。文中的线路含义引用本站已发布的线路页；自治系统名称在 2026-11-12（北京时间） 对照过 IPinfo 与 PeeringDB 公开登记；付款周期的例子来自搬瓦工官网公开目录（同日核对）。没有自购新的性能测试，本文不下新的速度或丢包结论。

先说结论#

先看访客主要在哪，再决定要不要精品线路，然后选靠近访客的机房，最后用同一方案核对月付、年付和续费条件。不要先被套餐名或活动价带着走。

可以按下面五步走：

  1. 分清访客主要在中国大陆，还是在目标市场（美国、欧洲、东南亚等），两边都有也要先写清楚，不能混成“外贸站所以一定要 CN2”。
  2. 只有大陆访客占比高、又在意晚高峰稳定性，或国内团队要经常从大陆访问后台时，再进入精品线路的判断；访客主要在海外时，普通国际线路往往就够。详见 国内访客为主，独立站该不该上 CN2 和 独立站要不要上精品线路。
  3. 机房先靠近主要访客，而不是靠近你所在的城市。配置先看本站 配置下限估算，不要一上来就买很高的套餐。
  4. 比价时看同一方案的月付和年付差额，并核对续费是不是同一档标价，而不是只看首期。见 年付和月付差多少，续费会不会更贵。
  5. 上线前后，用目标市场的访问路径做验收。本站目前公开发布的境外体检是 RF-KEY射频元器件商城海外访问实测；没有自购实测，就不会在这里补充性能数字。

服务器只是出海成本里的一笔。先立主体、再开门面、把货送出去、把钱收回来，地图在 首页出海成本地图。这一组文章只展开“开门面”里的服务器和网络。

先问访客在哪#

独立站的服务器，首先是给访客打开的，其次才是给你自己维护的。把访客写成“国内外都有，所以全都要最好”，后面的线路和机房都会失去判断标准。

主要访客先看什么再读哪一篇
主要在中国大陆，例如国内询盘、国内分公司或需要大陆打开后台要不要 CN2 GIA，以及联通、移动访客要不要对照 9929 / CMIN2国内访客为主，该不该上 CN2
主要在海外目标市场机房靠近访客，普通国际线路通常即可；先解决页面体积、HTTPS 和多语言，再谈换线路访客主要在海外时怎么选
大陆和海外都有，且都要经常访问按占比和高峰时段拆开看，可能是一台靠近海外访客的机器，再另作大陆访问或后台方案；不要默认买一条最贵的线路就两端都合适要不要上精品线路
还不确定先看统计、询盘来源和你真正要服务的市场；不确定时不要先给线路下结论线路对照工具

本站 线路对照 的规则只来自三篇线路页，不补充延迟或丢包数字：大陆电信访客去读 CN2 GIA，联通去读 9929，移动去读 CMIN2；主要不在中国大陆时，这三篇谈的是大陆回程，不替你选线路。

配置先看下限，再去比价#

本站 配置下限估算 把常见独立站写成这样的起步假设（不是实测评分，也不是“越多越好”）：

工作负载起步下限工具里的上调假设
静态展示站1 vCPU / 1024 MB月访问量大于 10 万次时，内存改为 2048 MB
CMS（一个站点，带数据库，例如常见的独立站建站程序）1 vCPU / 2048 MB月访问量大于 5 万次时，改为 2 vCPU / 4096 MB
小型 JSON API2 vCPU / 2048 MB按峰值再上调；超过工具上限时不估算多台机器

工具写明：留空表示“不知道”，不是 0；超过 1000 万次/月或 1000 次/秒时，这张表不给配置。算出下限后，再去 服务器比价 里筛内存和 vCPU 都不低于该下限的套餐。未知配置会被排除，因为未知不等于达标。

RF-KEY射频元器件商城 的公开结论也和这个顺序一致：2026-11-02，本站用自购的搬瓦工洛杉矶普通线路月付机器（4 核 4 GB，$19.99/月，核对价见该文）从美国加州访问公开页面，页面可以打开；完整加载偏慢的主要原因是首页图片体积，报告写明单靠升级服务器解决不了这一项。业务和访问量变大、或大陆访问明显偏慢时，再考虑更高配置或大陆优化线路。

线路、地区和付款周期怎么接起来#

  • 线路：CN2 GIA、9929、CMIN2 各适合哪类大陆访客，见 独立站要不要上精品线路。详细定义仍在 CN2 GIA、9929、CMIN2 原线路页。
  • 地区：访客在美国就先看美国机房，在东南亚就先看新加坡等靠近访客的节点。本站比价页按地区列出已收录套餐，例如 美国、新加坡、日本、中国香港、德国、英国。
  • 付款周期：年付常常比把月付买满 12 个月更省，但要核对是不是同一档标价、退款是否包含续费、首期优惠会不会在续费时消失。例子和算法见 年付和月付。

想先用免费额度做试验，可以读 免费服务器与新用户赠金汇总 2026 和 Oracle Cloud Always Free 申请指南，并以这两篇自己的核对日期为准；免费机有额度、区域和回收规则，不能直接当成正式独立站的默认方案。

使用时要注意什么#

  • 本站线路页写明：表现因机房、时段和所在地区而异，实测完成前不给速度结论。本文遵守同一条。
  • 活动价、库存和优惠码会变。本站优惠文章各有自己的核对日期，例如 搬瓦工方案对比 的目录核对应以该文页面为准；本文不把任何活动写成今天仍在进行。
  • 含推广的跳转会标明。结论按适不适合排，不按佣金排。

常见问题#

Q：独立站一定要买海外服务器吗？

A：要看访客和业务发生在哪。站点主要服务海外客户，机器通常放在靠近访客的地区，避免只把服务器放在自己身边。若访客和操作都在中国大陆，海外机器不是自动正确的答案。主体、域名和收款还要单独看，地图在首页出海成本地图。

Q：访客在国内和海外都有，买一条精品线路能不能两端都顾到？

A：不一定。精品线路讨论的主要是中国大陆回程，不自动等于海外目标市场也会更快。两边都有访问需求时，按占比和高峰拆开看，不要默认最贵的线路就两端都合适。本站没有为“一条线路覆盖全球”做过实测，因此不下这个结论。

Q：先买便宜的月付，以后再升级，可以吗？

A：可以，尤其是站点还在试验内容和市场的时候。先用配置下限估算起步，月付方便停掉或改方案。等访问来源稳定，再决定要不要换地区、换线路或改年付。RF-KEY射频元器件商城那次境外体检也说明：页面资源过大时，先减重，而不是先升级机器。

Q：免费云服务器能不能先用来建独立站？

A：可以用来熟悉流程或做短时试验，但要把额度、可用区、闲置回收和验证条件看完，并以本站免费机指南各自的核对日期和官方页面为准。正式对外卖货的独立站，还要另外核对地域、备份、邮件发送和售后时段的运维条件，不能把免费机直接写成默认方案。

Q：这篇和比价页、优惠汇总是什么关系？

A：这篇只给判断顺序。算出配置下限、选定地区和线路类型之后，再去服务器比价筛选套餐；核对某一家的标价或活动时，再打开对应的商家或优惠文章，并看该文的核对日期。不要反过来先从活动列表倒推需求。
